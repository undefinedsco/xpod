# Session collection read loses the document source during inline hydration

The real standalone Gateway acceptance of the working tree based on `685e7e1496967a33c464538be2dbcb173be85329`, after the shared SolidFS authentication repair, reached approved, rejected and Stop terminal Sessions. The immutable RC for that base SHA had failed earlier during resume and remains rejected. Cleanup nevertheless failed. This is not an absent Session or a failed scoped query: the authenticated `/.data/sessions/-/sparql?query=...` request returned HTTP 200 with six Session rows, and independent exact reads returned HTTP 200 for each current-run Session. The extra read addressed `/.data/sessions/` and returned 404.

`sessionResource` is the shared model with date-document ids (`{yyyy}/{MM}/{dd}/{key}.ttl`) and an optional object metadata column. In drizzle-solid 0.3.25, `SelectQueryBuilder.hydrateInlineColumns` groups parent subjects using `inferSourceFromChild`. That helper preserves the document URL for subjects containing a fragment, but falls back to the table base for full HTTP(S) subjects without a fragment. Date-document Session subjects therefore lose their concrete source even when the metadata value is absent.

Reproduce using the real shared Session schema and `db.select().from(sessionResource)`: return one date-document subject from its configured SPARQL endpoint, serve that exact document as Turtle, and reject the collection root. The query currently fetches the root and fails. The regression also covers a fragment subject, preserving its complete subject identity while addressing only its containing HTTP document.

The repair belongs in the shared query builder, consumed through Xpod's existing version-pinned CJS/ESM dependency patch. A complete HTTP(S) parent subject without a fragment is already its concrete document source; use it directly. Fragment subjects continue to address the same containing document. Do not derive dates or Pod roots in Xpod business code, suppress 404s, skip Session verification, change identity comparisons, or relax storage authorization.
