# Workspace normal pack/consumer custody

`scripts/collect-workspace-normal-run.cjs ROOT SOURCE_SHA OUTPUT` wraps the existing `workspace-package-consumer.cjs --local` command **once**. It does not implement another packer, package catalog, consumer or build. It uses the existing `PACKAGES`, normalizer, archive inspector and the shared owned command runner introduced by the AFS publication wiring patch.

OUTPUT must be fresh under an existing canonical parent. No candidate workflow wiring or actual large producer run is included here. The existing normal command still needs its ordinary installed build tools and completed build outputs. The collector does not install or rebuild anything itself.

The retained `normal-run.original.json` uses the existing workspace-consumer-acceptance kind/schema. Its `execution.phase` is one **composite** pack-plus-consumer phase. `command`, `args`, `cwd`, `actualReturnCode`, `signal`, `waitStatus`, `actualClose`, `groupAbsent` and `rawClosedBeforeHash` describe that actual command. The collector independently requires actualWait/rawComplete/rawClosedBeforeHash true, known wait, null signal, exact zero exit, and two true pipeEOF values before accepting any returned result; it rejects unknown/truncated/I/O-incomplete raw rows even if a caller hook returned success. It does not overwrite missing/false rawClosedBeforeHash using rawClosed. `code` and `rawClosed` remain the shared runner's original field names; the explicit aliases have the same measured values. The collector requires exactly two distinct ordered raw references named normal-pack-and-consumer.stdout.raw.log and normal-pack-and-consumer.stderr.raw.log, then rehashes both after command closure. Duplicate, missing, reversed and other-label references fail independently of the reader. It does not invent per-package or nested Bun phase results.

`execution.collector` and `execution.commandRunner` bind their actual files; `execution.tools` binds the existing producer/consumer tools. `execution.sourceBefore` and `sourceAfter` reference the original input inventories. Each inventory has the actual Git HEAD, clean-state/status hash, all supported tracked inputs (regular files and Git mode120000 symlinks, with path/mode/bytes/SHA256/Git blob/matchesGit), and the original Git head/status/tracked-index command outcomes and stdout/stderr references. `inputSHA256` hashes the stable input projection, excluding before/after raw filenames. Dirty/mismatched input or changed before/after bytes fails.

`workspaceEvidence` references the unchanged original file produced by the child emitter. The collector does not trust its ok/status. `archives` references the actually retained normal originals and recomputed exact name/version/bytes/SHA256/SRI. The normal archive manifests and dependency declarations are checked against the current source manifests via the same shared normalizer. Missing, duplicate, mutated or mismatched originals fail.

The reader must rehash the original referenced files, validate the expected immutable Git source and original input inventory, check the one actual composite outcome and raw logs, and validate the exact archives. Old receipts without these originals remain blocked. A child ok/status boolean is not a substitute for those facts. Caller-supplied execute hooks exist only for tiny fixtures; a fixture receipt is not real product evidence.

`buildAuthority`, `sourceAdmission`, `registryAdmission` and `releaseQualified` remain false. This collector proves custody of the normal pack/consumer execution and measured input state, not an earlier build execution, complete dependency closure or release authority. Keep these missing gates separate. POSIX group absence is the runner's actual observation; arbitrary detached-daemon absence is not claimed, and unsupported Windows group observation cannot pass.

This delta uses the one independently reviewed v3 command runner SHA256 `97980fdad10a7d078aac8746c5ed2549e24419fb67de63f16438e45f7493e8be` from the AFS wiring patch; it does not introduce a second runner. The collector, small fixtures and this document form the delta. No CI trigger, candidate acceptance or reader relaxation is included.

Tracked mode120000 inputs retain mandatory linkTargetBase64 of the original readlink Buffer. Their bytes/SHA/Git blob describe the link target string, never the target file. Relative UTF8 POSIX targets must stay lexically inside the source root; absolute, Windows-absolute, backslash targets and symlink ancestors fail. lstat before/after binds link identity while reading. Gitlink/conflict modes stay explicitly unsupported. This source-only compatibility change does not reclassify a previous failed normal run as successful.
