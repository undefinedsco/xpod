# W6 桌面资产与生命周期 · 设计自查与实施范围

### 范围与职责

- 模块 / 负责人：桌面产品资产、托盘与退出行为、旧资产归档（W6）
- 审查日期 / 纲领与实施 spec 版本：2026-09-27 / 纲领 R2、实施 spec 2026-09-27 R2
- 适用设计决定 D 编号 / 实施验收 AC 编号：D-05、D-07；AC-02、AC-12
- 用户任务（一句话）：从菜单栏就知道 Xpod 现在怎么样，并清楚每个退出动作到底会停掉什么
- 场景：macOS 桌面壳（Dock 图标、菜单栏托盘、窗口生命周期）、Web 控制台不涉及
- 本模块负责 / 不负责：负责品牌资产引用、平台图标、托盘状态与退出动作的真实表达；不负责服务端生命周期语义（9/19 canonical 与 runtime owner）
- 前置模块 / 完成后去向：W1 品牌参数、W2 宿主能力；后台运行能力按其真实依赖（§11）表达，不在此模块发明
- 审查层次：文档 + 前端/宿主表达（读取 `desktop/src/tray-icon.ts`、`tray-menu.ts`、`main.ts`、`window-lifecycle.ts`、`dock-icon.ts`、`desktop/assets/`；未运行应用）
- 已阅读的文件、章节或行号：
  - `desktop/src/tray-icon.ts`（template 资产命名 + 稳定 GUID）、`tray-menu.ts`（聚合状态、服务行、退出动作）
  - `desktop/src/main.ts:439-449`（trayIcon/createTray）、`main.ts:535-538`（退出确认文案）
  - `desktop/assets/`（`tray-{healthy,starting,degraded,failed,stopped}Template.{svg,png,@2x.png}`、`icon.icns`、`icon.iconset`、`icon-master.png`）
  - 实施 spec §9.1–§9.3、§5.1、§11、§12 W6；AC-02/AC-12；纲领 XP-10/XP-12
- 未覆盖范围：真机菜单栏/Dock 行为、签名与分发、后台代理（独立安装/控制通道）按 9/19 的后续工作

### 功能与操作是否成立（先于规则合规）

| 功能 / 入口 | 用户要作的决定 | 没有它哪条任务受损 | 判定 | 理由和受影响能力 |
|---|---|---|---|---|
| 托盘状态 | 现在是否正常 | 用户要开窗口才知道状态 | 符合 | 五态图形 + 文字聚合标签 + 服务计数（E-02/E-06） |
| 托盘动作 | 打开、看日志、退出 | 出问题时找不到证据入口 | 符合 | 崩溃服务直达带 source 的日志（E-06） |
| 退出动作 | 退出会不会停服务、会不会影响别的东西 | 用户不敢退出，或退出后发现服务停了 | 保留（需说明分层） | 确认文案已说明会停服务（E-07）；关闭窗口与退出登录的区别未在 UI 说明（见 W6-DESIGN-02） |
| 平台资产 | 不需要决定 | 图标缺失或与品牌不符会显得不可信 | 缺证据 | 托盘资产齐全，但来源/校验值未记录（见 W6-DESIGN-03） |

### 结论

- 最重要的设计结论（不超过三项）：
  1. 托盘状态表达已符合 §9.1/§9.2（五态单色标 + 文字 + 崩溃直达日志）；
  2. 生命周期动作的分层说明是主要缺口（P2），且其中一部分依赖 9/19 尚未决定的语义，不应由桌面壳自行发明；
  3. 资产可追溯性缺一份清单，属低成本补齐项。
- 值得保留的设计：`tray-*Template` 模板图与稳定 GUID（保持菜单栏位置）、聚合状态里带 `running/total` 与服务名、失败的日志直达带 source。
- 本模块可修正事项 / 公共层事项 / 待决定事项：可修正 01、03、04；核对 02；待决定事项来自 9/19 D-14/D-18。
- 本次仍缺少的设计或前端材料：真机菜单栏/Dock 走查、D-14/D-18 的语义结论。
- 本轮结论范围：文档 + 宿主表达审查；未运行应用。
