# 桌面外壳与共用 applet 实施记录

依据：2026-10-01-xpod-desktop-shell-and-applets-design.md。实施分支：codex/desktop-shell-applets。

## 重组计划

1. 用现有登录、运行时与 Pod API 保留身份/保存/重建行为，先跑既有针对性回归。
2. 导航收敛为任务、AI 连接、Pod；这台设备与设置放底部。旧路径重定向，移除重复模型/客户端编辑入口。
3. AI 连接继续使用现有 applet，Pod 与任务提供无宿主 rail 的共用 body；宿主负责导航、能力声明与连接。
4. 通知与托盘使用同一份待处理对象投影；已读只影响动态，审批通过来源对象处理。
5. Task 合同先在 models 隔离 worktree 补字段和测试，再消费；本仓库不另建共享 RDF schema。
6. 按 API 已有能力实现操作；设计列出的后续项及缺失合同标待接入，不显示虚构成功状态。

## 验收清单

- WebID 登录入口保留，未登录时设备/设置可达；个人卡片显示 WebID、Pod 与账号管理外链。
- 1280/390 宽、深色、200% 文字：rail/列表/内容、抽屉、弹层、标题无重复或溢出。
- 新建密钥两步、复制能力降级、模型标签与凭据池、单一 embedding 更换与重建确认。
- 通知需要处理/动态分离、收件箱审批、托盘上限三条与退出确认。
- 待办持久化、截止日期/完成状态、清单/日程、公开任务操作与同次运行的数据来源。
- build:ts、typecheck:test、test、test:integration、ui build:dashboard 与桌面测试。
- 按设计 §13 在隔离 Standalone 进行运行/页面验收，结果明确区别于用户真实实例。
